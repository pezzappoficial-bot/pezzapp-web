# Web de PEZZAPP

Página de presentación y política de privacidad de la app PEZZAPP.

- `sitio/`: la web (HTML y CSS propios).
- La letra Nunito (OFL) y three.js (MIT) no se guardan aquí: `scripts/recursos.sh`
  los descarga y comprueba al publicar.
- Cada cambio en `main` se publica solo con la acción **Publicar web** (GitHub Pages).
